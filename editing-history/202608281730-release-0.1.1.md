# 发布 0.1.1 / Release 0.1.1

- 同步 `Cargo.toml` 与 `deps.cirru` 的模块版本为 `0.1.1`。
- 发布首个完整采用 `calcit_native_ffi` C-safe EDN ABI 的 DBT 版本。
- DBT 值在 Calcit 边界改用无损 `Buffer` 表示，避免跨动态库传递 Rust `AnyRef`。

---

- Synchronized the module version in `Cargo.toml` and `deps.cirru` to `0.1.1`.
- Released the first DBT version fully backed by the `calcit_native_ffi` C-safe EDN ABI.
- Represented DBT values as lossless `Buffer` values at the Calcit boundary instead of passing Rust `AnyRef` values across the dynamic-library boundary.
